# TGDeviceMask — iPhone 17 Pro внутри Telegram

Rootless-твик для официального Telegram из App Store (`ph.telegra.Telegraph`).
Настройки по умолчанию: аппаратная строка `iPhone18,1`, имя для MTProto — `iPhone 17 Pro`.

## Что меняется

- В процессе Telegram перехватываются `uname`, `sysctlbyname("hw.machine")` и `sysctl` с `CTL_HW/HW_MACHINE`.
- В `MTApiEnvironment` перехватывается инициализация модели, методы `platform`, `platformString`, `deviceModel`, `deviceModelName`.
- Имя подставляется в инициализатор до формирования внутреннего хеша параметров соединения. Повторное создание и копирование окружения использует ту же модель.
- Фильтр загрузчика и проверка bundle ID ограничивают действие основным приложением Telegram. Расширения уведомлений, другие клиенты и приложения не охватываются.
- При отсутствии ожидаемого класса/методов либо повреждённом конфиге перехваты не устанавливаются, причина выводится в системный журнал.

IMEI, серийный номер, Apple ID, версия iOS, размер экрана и аппаратные возможности остаются прежними. Это подмена сообщаемой модели, а не превращение телефона в другое устройство.

## Статус проверки

Исходники подготовлены по публичному исходному коду Telegram, commit `f1dd7a2dbd02cbbf513e75d5695d8d36d1cf5838`.
Препроцессор Logos успешно обработал `Tweak.x`; XML обоих plist проверен. Это не компиляция и не проверка на устройстве.
В этой среде Windows нет Xcode, iOS SDK и установленного Theos: `.deb` здесь не собран и работа на iPhone не проверена. Архив содержит исходники и готовый workflow сборки, а не установочный пакет.
Конкретная установленная версия Telegram и результат в серверном списке сеансов требуют проверки на телефоне. Наличие класса в исходниках само по себе не подтверждает его наличие в любой сборке приложения.

## Сборка без Mac: GitHub Actions

1. Создай пустой репозиторий GitHub. Можно приватный. Загрузи содержимое папки `TGDeviceMask` **в корень** репозитория: рядом должны лежать `Makefile`, `control`, `Tweak.x`, `TGDeviceMask.plist` и папка `layout`.
2. Добавь файл `.github/workflows/build.yml` из архива с сохранением пути. Скрытая папка `.github` может не попасть в обычную загрузку через браузер; тогда создай файл через **Add file → Create new file**, введи полный путь `.github/workflows/build.yml` и вставь содержимое.
3. Открой **Actions → Build rootless deb → Run workflow**. При необходимости разреши Actions для репозитория.
4. После успешной сборки скачай артефакт **TGDeviceMask-rootless**, распакуй ZIP. Внутри будет `.deb` (обычно в папке `packages`) и список содержимого пакета.
5. Красный статус workflow означает ошибку сборки: `.deb` нельзя считать готовым, смотри первый упавший шаг. Workflow не запускался при подготовке этого архива.

Workflow использует macOS, Xcode runner, Theos, `dpkg`, `ldid`. Сборка включает `-Wall -Wextra -Werror`; шаг проверки проверяет архитектуру пакета и пути `/var/jb`. Сетевые зависимости берутся из их текущих веток, поэтому сборка не является воспроизводимой по фиксированным версиям всех инструментов.

## Сборка на Mac

Нужны полный Xcode с принятым лицензионным соглашением и установленный Theos:

```sh
export THEOS="$HOME/theos"
cd /path/to/TGDeviceMask
make clean package FINALPACKAGE=1
```

Готовый пакет — `packages/*.deb`. Цель `arm64` выбрана для App Store приложения; отдельный `arm64e` для такого процесса не требуется. Rootless-схема задаёт Debian-архитектуру `iphoneos-arm64` и префикс `/var/jb`.

## Установка на iPhone через Filza

1. В Dopamine должно быть включено внедрение твиков; jailbreak должен быть активен. Через Sileo проверь наличие **ElleKit**. Если у тебя есть менеджер исключений твиков, разреши внедрение для Telegram.
2. Установи rootless-совместимую **Filza** через Sileo, если её ещё нет.
3. Перенеси **собранный `.deb`**, а не ZIP исходников, на телефон. Открой его в Filza, нажми **Install / Установить** и дождись успешного завершения. Если предложен respring — выполни.
4. Полностью закрой Telegram через переключатель приложений и запусти снова. Простое сворачивание не перезапускает процесс.
5. Открой **Telegram → Настройки → Устройства**. Дай приложению установить соединение. Для независимой проверки открой список устройств с другого уже авторизованного клиента.

## Альтернатива: терминал телефона

После установки терминала через Sileo сохрани пакет как `/var/mobile/Downloads/TGDeviceMask.deb`. Выполни с правами root:

```sh
dpkg -i /var/mobile/Downloads/TGDeviceMask.deb
```

Права root получаются через `sudo` или `su` в зависимости от настройки твоего jailbreak. Пароль здесь не задаётся. Ошибки зависимостей исправляются через Sileo; не игнорируй их с `--force`.
После успешной установки полностью перезапусти Telegram.

## Если активный сеанс всё ещё показывает iPhone 11

Список сеансов хранится на стороне сервера. Перезапуск с новым `device_model` не гарантирует немедленного переименования существующей авторизации; твик не переписывает отображение списка локально.

1. Проверь, что пакет установлен, jailbreak активен, Telegram не исключён из внедрения и нет другого твика подмены модели.
2. В системном журнале процесса Telegram найди `[TGDeviceMask]`. Строка `MTApiEnvironment interface unavailable` означает, что установленная сборка Telegram не соответствует ожидаемому интерфейсу и твик отключился. `Hooks requested` означает вызов установки перехватов, а не подтверждение ответа сервера.
3. Полностью закрой и открой Telegram, обнови список устройств с другого клиента.
4. Если нужно проверить именно **новую авторизацию**, можно выйти и войти заново после установки твика. Делай это только имея доступ к коду входа и паролю двухэтапной проверки. Выход приводит к потере секретных чатов на этом устройстве. Для первой проверки выход не нужен.

Если проблема остаётся, для адаптации нужны номер версии/сборки Telegram и строки журнала `[TGDeviceMask]` без личных данных. Автоматической совместимости с будущими изменениями Telegram здесь нет.

## Настройки и удаление

Конфиг на телефоне:

```text
/var/jb/Library/Application Support/TGDeviceMask/config.plist
```

Редактируется в Filza. `Enabled = false` отключает все перехваты после полного перезапуска Telegram. `ModelIdentifier` задаёт строку `iPhone18,1`, `DisplayName` — `iPhone 17 Pro`. Настройки читаются один раз при запуске процесса. Обновление/переустановка пакета может заменить конфиг.

Удаление: **Sileo → Установлено → TGDeviceMask → Удалить**, затем полностью перезапусти Telegram. Либо с правами root:

```sh
dpkg -r local.telegram.devicemask
```

Удаление возвращает приложению настоящую модель; уже сохранённая серверная запись сеанса может обновиться позднее.
